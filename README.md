# Cheliah Fitness App 🚀

A premium Flutter-based fitness tracking application focused on immersive workout experiences, smooth animations, and modern UI interactions.

---

## ✨ Features

- Dynamic workout sessions
- Weekly & monthly progress tracking
- Interactive workout timers
- Streak system & gamification
- Media control integration
- Animated workout flow
- Glassmorphism + neon UI aesthetic
- Dynamic motivational welcome screen
- Workout completion animations
